# Військова Справа Гетьманату

Більшість населення військовозобов'язане. Постійну службу несе лише клас козаків (сердюки, гайдамаки, гайдуки, пластуни), яничарів та моджахедів. Під час війни обирається наказний Гетьман із необмеженою владою.

Війська поділяються на декілька класів :
    1. Гайдуки. Несуть службу на планетах та захищають їх від нападів. Мають обмежений арсенал, без важкого озброєння. Мають міжпланетні літаки для патрулювання. 
    2. Сердюки. Ударні війська Гетьманату. Мають засоби для ведення війн в межах галактик. Можуть штурмувати чужі планети та системи. Різноманітні засоби ураження, мають надважкі плазмові гармати для руйнування планетарного захисту та ядерні заряди.
    3. Пластуни. Розвідники та харасери. Легка космічна піхота. Перевага у мобільності, здатності приховувати переміщення. Не мають важкого озброєння. Беруть участь у розвідці та патрулюванні простору.
    4. Гайдамаки. Неофіційно — козаки Федерації, займаються протизаконною діяльністю, схваленою Січчю. Наприклад, напади на інші колонії та захоплення ресурсів. Використовуються де-факто для нападів на інші імперії, але без де-юре наслідків.
