# Loca Deserta Sci-Fi contributor instructions

## The universe name is never translated

The universe is called **Loca Deserta** in every language except Ukrainian,
where it is **Дике Поле** (with normal Ukrainian declension: Дикого Поля,
Дикому Полю, …).

- Never translate the name: no "Wild Field(s)" in English, no "Wilde Felder"
  in German, and no literal translation in any other language.
- This also covers names built from it: the colony is "Loca Deserta 17"
  (Ukrainian «Дике Поле 17»), and the book series is "Loca Deserta Sci-Fi".
- It applies everywhere: notes in `content/`, site strings in `src/`, the
  scripts in `scripts/`, EPUB configs in `epubObsidianConverter/`, and any new
  translation.
